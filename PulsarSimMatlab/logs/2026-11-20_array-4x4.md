# 20 Nov 2026: the array becomes 4×4 on the same area (notes, docs and comments; no function changed)

Jasper, at the start of the session ("Development continuation!"): "I have an update: the array will be still the same area, but
now 4x4!" Then: "Also further, i will have an update for the ways digital beams are coming in", and "and yes, record the update".

## What it means
16 elements on the same 0.61 m², instead of 9.

- **Unchanged:** A_eff (0.61 m² nominal, 0.3 m² worst case), the SEFD, the array gain (~22 dBi), the beam (~15°), and so every TOA and
  position budget, the RFI scenario levels and the D6 numbers of 4 Nov. The fast simulator knows only A_eff, T_sys and n_pol. No live
  function depends on the number of elements; the array is step E4.
- **Changed** (Claude's estimates for a square grid that fills the area; not measured, not simulated):

| | 3×3 | 4×4 |
|---|---|---|
| elements / streams (dual polarisation) | 9 / 18 | 16 / 32 |
| element pitch (side √0.61 = 0.78 m) | 0.26 m | 0.195 m |
| pitch in wavelengths, 1.2 / 1.4 / 1.6 GHz | 1.04 / 1.21 / 1.39 | 0.78 / 0.91 / 1.04 |
| element area | 0.068 m² | 0.038 m² |
| element gain 4πA/λ² at 1.4 GHz | 12.7 dBi | 10.2 dBi |
| per-element signal-to-noise | 1 | 9/16 (−2.5 dB) |

- Grating lobes: one enters real space beyond a steering angle of asin(λ/d − 1). 3×3: the pitch is above one wavelength over the
  whole band, so always, at 74° off axis at 1.2 GHz and 46° at 1.6 GHz for a beam at broadside. 4×4: beyond about 16° of steering at
  1.2 GHz and 6° at 1.4 GHz; at 1.6 GHz still present at broadside, 74° off axis. Free of them at every angle only with a pitch of λ/2,
  9.4 cm at 1.6 GHz.
- The element beam is about 4/3 wider, so the array steers further off its axis before the gain drops. That helps the beam pointing
  for a site that is not known beforehand (open decision 4 of `2026-11-13_handover-static-nav.md`).
- Hardware: 32 streams of 400 MHz and 32 LNAs. The Task 2.4 front-end candidates of 19 Nov were sized for 18.
- Element calibration on a sky source gets 2.5 dB harder per element. The beamformed sum is unchanged.
