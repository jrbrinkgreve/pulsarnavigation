## Work done

- Discussion: how physically accurate is the pipeline, and how relevant is interstellar
  scintillation? Conclusions recorded in `current_project_notes.md` §9 (no code changes,
  no MATLAB runs). In short:
  - Exact (and validated) for what it models over 0.1–1 s: AM-noise signal statistics,
    cold-plasma dispersion + coherent dedispersion, receiver chain, fold, FFTFIT errors.
  - Simplified: white spectrum (real α ≈ −1.6), single stable Gaussian profile, ideal
    single-pol receiver.
  - SNR regime: −5 dB is a bright pulsar on a large dish; a 3 m antenna gives roughly
    −27 dB (Vela) to ≲ −50 dB (typical MSP).
  - Missing and dominant on navigation timescales: Doppler (~100 µs/s), DM variations
    (~2 µs per 1e-3 pc cm⁻³), clock, scintillation.
  - Scintillation at DM 5: τ_d ≈ 0.4 ns, Δν_d ~ 0.1–1 GHz → strong flux fading (SNR
    budget), negligible timing effect; at DM ≳ 100 scattering gives µs timing noise.
    Within a ≤ 1 s voltage sim it is a static random gain g(f); long-term fading belongs
    at TOA/SNR level.

## Later: bandpass / noise-bandwidth review (notes §10 item 6, now closed)

- Filters per component: pulsar W_f → IQ low-pass (flat in band, drops out) → W_i;
  receiver noise IQ low-pass → W_i only.
- Two bandwidths: ∫W² sets the mean power (390.0 MHz noise, 388.4 MHz pulsar);
  (∫W²)²/∫W⁴ sets the variance (391.6 / 389.6 MHz; ≥ ∫W² because the edges add
  fluctuations with little power).
- Where B is used: `estimateTOA` 391.6 MHz (W_i, observer; exact for noise, ≤ 0.5 % in
  variance for self-noise); `predictPerformance` flat 400 MHz (1.5 % optimistic);
  `expectedPowerModel` exact (css, csn, cnn).
- Conclusion (Jasper asked for a simpler explanation): all effects ≤ 1.5 % in the
  simulation, so not a big issue now; it matters for real data (non-flat bandpass,
  flagged channels) and for phase D, which compares FFTFIT against the prediction.
- Found: receiver noise does not pass W_f (physically it passes the same analog
  bandpass as the sky signal). < 1 % in SNR; documented, not changed.
- Correction to the first estimate: in the noise-dominated limit the effective B is
  (∫W_f²W_i²)²/∫W_i⁴ = 388.4 MHz (not 389.6), so the flat-band prediction is 1.5 %
  optimistic (not 1.3 %).

## Later: exact radiometer optimum (code change, 3 steps)

1. `expectedPowerModel.m`: new fields `snrPulse`, `toaErrPulse` = Fisher integrals
   SNR² = ∫Ps²/v dt, 1/σ² = ∫Ps′²/v dt with v = css·Ps² + 2·csn·Ps·Pn + cnn·Pn²
   (flat band → old formula). NaN without noise.
2. `main.m`, `runMonteCarlo.m`: print the predicted best TOA error / SNR from
   `expectedPowerModel` instead of `info_rx.prediction` (format %.4g).
3. `addNoiseAndRFI.m`: quick prediction kept, labelled "flat band, ~1.5 % optimistic"
   (header, print, `prediction.note`); no arithmetic change.

**Results:** Jasper ran it: `M.snrPulse` 96.5, `M.toaErrPulse` 2.892 µs at −5 dB (= Python
port); `main.m` prints 2.892 µs. Python table: the offset is 1.33–1.49 % from −40 to
+10 dB. Reinterpretation of the MC: mean σ 2.907 µs is 0.5 % above the exact optimum
(not 2 %).

## Later: phase D – SNR sweep (`runSNRSweep.m`, new script)

Design agreed (plan): new script instead of extending `runMonteCarlo.m`; pulsar
realization varied (sky per realization, reused for all SNR values); seeds
`seed + 100·(j−1)` / +1 (j = 1 = main); grid −25…+20 dB at 1 turn per sub-int (covers
the threshold region and the self-noise regime; realistic −30…−50 dB maps onto the low
end via longer sub-ints); optimum from `expectedPowerModel`.

- Quick test (2 realizations, −5/+10 dB): built-in check passed (93.4 / 2.880 µs);
  +10 dB ratio 0.56 on 18 TOAs (flagged, turned out a fluke).
- Full run (10 × 8, 11.6 min): table and conclusions in `current_project_notes.md` §7.
  In short: error bars honest for SNR per sub-int ≳ 10 (rms/pred 1.03–1.06 from −15 to
  +20 dB); outliers below (5.6 % at SNR 3.8, 57 % at 1.2); FFTFIT optimal up to −5 dB,
  1.50× at +10 dB, 2.38× at +20 dB (saturates at ~0.47 µs).
- Plot fix: middle panel had a log axis up to 12 (−25/−20 dB outliers) that squashed the
  ratios near 1 → linear 0.8–3 with off-scale points on the edge, labelled; title
  "Ratios"; legend northeast. New switch `replotOnly` redraws from `snrSweep.mat`
  (default false).

## Decisions

- Keep the voltage pipeline as it is; scintillation not added now. If added later: a
  static g(f) in the forward filter (+ optional multipath tail).
- Phase D sweep range should extend below −30 dB (realistic small-antenna regime).
- Phase D compares against `expectedPowerModel` (exact), not the flat-band prediction.
- W_f / receiver-noise inconsistency: documented only.
- Phase F (weighted fit) low priority: it only gains at high SNR, while realistic
  navigation is weak-signal. Phase E (noise normalization + NP detector) next.
- Pipeline rule confirmed: sub-int length for SNR ≥ 10; navigation needs outlier rejection.

- RFI: no excision yet; follow-ups are a red. χ² TOA flag (phase E) and excision before
  dedispersion (Block 2).
