## The goal, in one paragraph

Pulsars tick like clocks. A pulse arriving earlier than predicted means we are closer to
that pulsar (by c × time difference). Arrival times (TOAs) from ≥ 4 pulsars in different
directions give a 3-D position plus a clock correction. The project builds (1) a
realistic simulator (pulsar → interstellar medium → our receiver, with ground truth) and
(2) the processing pipeline (receiver data → TOAs with honest error bars → later a
position), and checks every processing stage against the simulator's ground truth.

```
SIMULATOR                       PROCESSING (what would run on real antenna data)
pulsar signal → dispersion  →   receiver noise/RFI → IQ → dedisperse → detect power
                                → fold over the period → TOA fit + detection → (later: position)
```

## Session by session

**29–30 Sep — the noise-free pipeline.** All stages built (generator, dispersion, IQ
conversion, coherent dedispersion, power detection, folding, TOA fit = FFTFIT); a TOA
bias fixed; project notes started.

**1 Oct — noise in, first validation.** Receiver stage (`addNoiseAndRFI`) in the
pipeline; refactor (`pipelineParams.m`, helpers in `functions/`). Reference run at
−5 dB: SNR 93.4 per pulse, σ_TOA 2.88 µs (optimum 2.85). Monte Carlo over 10 noise
seeds: error bars honest (scatter / prediction 0.95).

**2 Oct — review only.** The mathematics behind each stage; no code changes.

**5 Oct — how realistic is it?**
- Exact for what it models over 0.1–1 s; missing: realistic SNR (−5 dB is a big dish),
  Earth's motion (Doppler), DM variations, scintillation.
- Bandwidth review: edge effects ≤ 1.5 %; predicted optimum made exact.
- SNR sweep −25…+20 dB: error bars honest above SNR ≈ 10 per sub-int, outliers below;
  FFTFIT optimal in the weak-signal regime.
- First RFI test: carriers / GNSS cost SNR; impulses harmless (dedispersion spreads
  them); **radar destroys TOAs while reporting confident error bars**. GNSS-RFI crash
  fixed.
- Detection started: `detectPulsar` ("is the pulsar there?") + χ² quality flag.

**6 Oct, morning — Block 1 (noise and detection) closed.**
- "Good TOAs" (detected + χ² ok) contain no outliers.
- Long noise-only run: false-alarm rate as designed, noise model right (incl. correlation
  of neighbouring phase bins).
- Design rule: **SNR ≥ 6–7 per sub-integration** for a usable TOA.
- A +3.7 µs offset in a check function was a statistical fluctuation.

**6 Oct, afternoon — what we design for.**
- Jasper's hardware: 3×3 array 0.61 m², T_sys 60–80 K, both polarizations, 1.2–1.6 GHz,
  ground station, should work anywhere.
- Worst case chosen: system noise ~7.4e5 Jy → pulsar ~**54 dB below the noise**.
- ATNF pulsar catalogue:

| Source | Hours per TOA (worst case) | Precision per TOA | Visible from |
|---|---|---|---|
| J0437−4715 (millisecond pulsar) | ~20 h | ~12 µs ≈ 3.6 km | south of ~23° N |
| Vela | ~0.3 h | ~146 µs ≈ 44 km | south of ~25° N |
| B0329+54 | ~4 h | ~570 µs ≈ 170 km | north of ~15° S |
| other millisecond pulsars | hundreds–thousands of hours | — | — |

  Per hour of observing, Vela is about as good as J0437 because it is so bright.
- Consequences: a TOA needs folding across *days* of passes → Earth's motion must be
  modelled; one pulsar fixes only one direction → ≥ 4 pulsars, so normal pulsars too;
  from Europe no millisecond pulsar is visible.
- Decided: DM up to 100 (includes Vela); sky temperature counted in the system noise.

**6 Oct, evening — plan changed, front end built.**
Jasper: real data contains RFI; simulations without it are not realistic. At −54 dB one
radar pulse ≈ 80,000 pulsar pulses, so RFI must be **cut out** (blanked) before
dedispersion smears it. That needs a **channelized front end**: split the band into
narrow channels, blank RFI per channel, dedisperse per channel, and keep track of how
much valid data went into each point.

Built (all validated by Jasper's test runs):
1. `channelizeIQ` — 400 MHz → 128 channels of 3.125 MHz (exact to single precision).
2. `dedisperseChannels` — dedispersion per channel, channels aligned in time (equals
   full-band dedispersion to 1e-5; TOAs agree within the predicted scatter).
3. Blanking experiment — blanking reduces the mean power exactly by the valid fraction;
   the *noise* follows no simple rule, but is exactly and cheaply computable.
4. `detectChannels` + `powerCovariance` — power per channel + exact noise numbers (in a
   narrow channel neighbouring time samples correlate; the old noise formula is ~1–3 %
   off, the new one matches the measurements).

Fixed along the way: tests are functions (several can run in one session); test pass
criteria from physics predictions, not guesses; measured runtimes in the test headers.
