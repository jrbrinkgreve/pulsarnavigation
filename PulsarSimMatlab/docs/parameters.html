Parameters: pipelineParams.m

Every parameter of the pipeline, its value, what it means, why it has that value, and which stage uses it. pipelineParams.m is a script: main.m and every run*.m call it, so they all use the same values.

Values checked line by line against pipelineParams.m as of commit 95a93bc (21 Oct 2026, its last change; checked 22 Oct). Edit parameters there, not in the scripts. Side: truth = only the simulator uses it; observer = the processing may use it (the ground-truth rule).

In short

One script, pipelineParams.m, sets every value. Truth parameters (the pulsar, the simulation, the noise and interference) only reach the simulator. Observer parameters (receiver, processing, ephemeris) are what the processing may use. The two pictures below show how the numbers fit together in frequency and in time; the tables after them give every value with the reason for it.

Design choice: excision writes its own files

Alternative: blank the channel files in place.

Why not: the unblanked channel files are the reference for with/without comparisons, and the source tests/makeTestData.m copies when the unit tests' data are re-frozen (the tests themselves read their own copy in data/test/ since 13 Oct); switching excision never overwrites them.
