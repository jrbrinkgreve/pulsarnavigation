Parameters: pipelineParams.m

Every parameter of the pipeline, its value, what it means, why it has that value, and which stage uses it. pipelineParams.m is a script: main.m and every run*.m call it, so they all use the same values.

Values as committed in 9b959f0. Edit parameters there, not in the scripts. Side: truth = only the simulator uses it; observer = the processing may use it (the ground-truth rule).

In progress (uncommitted): B6 switches

periodicMask = true (with excision, also blank every predicted pulse of periodic RFI found by periodicRFI) and periodicArgs = {}. To be added to the table when B6 is validated and committed.
