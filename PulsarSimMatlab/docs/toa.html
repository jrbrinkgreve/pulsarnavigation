Stage 8 · TOA estimation: estimateTOA validated

Fit a template to each folded profile: the shift gives the time of arrival, and a noise model that uses only the fitted profile and the fold's weights gives an honest uncertainty. On the channel path all channels are fitted together with inverse-variance weights.

1. The model and the TOA definition

p(φ) = a + b·s(φ − τ) + noise

s = template (peak 1 at phase 0), a = baseline, b = pulse amplitude, τ = phase offset from the ephemeris prediction.

TOA = tref + τ / fref

the arrival time of template phase 0 at the dedispersion reference frequency (1.6 GHz), with tref, fref from the fold's sub-int. toa.total (the whole fold) reports only the offset τ/f0 relative to the ephemeris, not an absolute TOA.

2. FFTFIT: finding the shift (Taylor 1992)

  1. Cross-spectrum Xk = Pk·conj(Sk) for harmonics k = 1…⌊N/2⌋−1 (DC carries only the baseline; Nyquist is ambiguous). C(τ) = Re Σ Xk·ei2πkτ is the continuous cross-correlation: a shift is a phase ramp in the Fourier domain, so any sub-bin τ is exact.
  2. Coarse search: zero-padded inverse FFT on 8×N points (1/8192 turn = 1.22 µs).
  3. Refine: Newton on C′(τ) = 0 with analytic C′, C″; steps clamped to one coarse step; C″ < 0 required; stop at 10⁻¹⁴ turns.
  4. b = C(τ̂)/Σ|Sk|²; a = (P0 − b·S0)/N; τ wrapped to [−½, ½).
Why FFTFIT

It is the standard pulsar-timing method: continuous shifts, fast, and the maximum-likelihood estimator for white noise (the weak-signal regime). The SNR sweep showed it within 1 % of the theoretical optimum up to −5 dB; it only loses at very high SNR where self-noise dominates (1.5× at +10 dB, 2.4× at +20 dB), irrelevant for the small-antenna target.

3. The uncertainty

τ̂ is where C′(τ) = 0, and C′ is a linear combination of the data: C′ = Σj dj·pj, with d from the template slope (largest on the pulse flanks). Noise moves C′ by δC′; the peak moves until C′ = 0 again: δτ = −δC′/C″. Therefore

var(τ) = dᵀ·Cov·d / C″²    (and similarly σb from C(τ))

This is first-order error propagation (the delta method). For white noise it equals the least-squares/Fisher error. For a Gaussian pulse it gives σTOA ≈ √2·σt/SNR.

The noise covariance Cov

'radiometer' (default): per time bin var = m²/(Bnoise·Δt), with m = a + b·s the fitted model (so the pulsar's own contribution, self-noise, is included). Per phase bin var = σtb²·weight2/weight², covariance with neighbours from weightX. 'offpulse': variance and lag covariances measured from off-pulse residuals.

Why the fitted model, and which bandwidth

The ground-truth rule: the observer does not know the true noise level, so σ comes from the fitted baseline and amplitude. main.m passes Bnoise = the noise bandwidth of the observer's own dedispersion taper (391.6 MHz; per channel 3.0596 MHz), not of both simulated tapers (389.6 MHz, which only the simulator knows). Receiver noise only passes the observer's taper, so this is exact for it; when the pulsar dominates (high SNR, in-pulse) the true value is ~0.5 % lower.

What the error bar does not know

It measures the sharpness of the correlation peak. It assumes you are on the right peak (at low SNR a noise peak can win: outliers) and that the template is right (otherwise χ² catches it). Hence detection and the χ² flag. In the 5 Oct radar test (full band, no excision) the fit locked onto radar spikes: stated σ ≈ 1 µs, actual errors ~2000 µs rms.

4. The χ² quality flag (phase E, 6 Oct)

χ²red = Σon-pulse (pj − mj)²/vj / (n − 3)

over on-pulse bins (model > 1 % of the peak, OnPulseFrac): normalized residuals squared and averaged. If the profile is template + noise with the predicted variance, it is ≈ 1 ± √(2/n) (≈ ± 0.09 for ~260 bins). flagChi2 = χ²red > MaxRedChi2 (2).

Why threshold 2

Far above the clean scatter and the known high-SNR excess (1.05–1.1), far below what a radar does (939–1625). It deliberately does not react to moderate RFI (χ² ~1.3 with a carrier), whose TOAs are still valid.

5. Combining channels: equal weights (A2a, 7 Oct)

For a fold with channels, 'Weighting','equal' (the default) sums the channel profiles: p = Σc profc. Shared helper combineChannels:

  • Exclusion rule: a channel is used only if it has data (W > 0) in every phase bin where any channel has data. A channel missing in some bins would leave a dip in the sum and pull the TOA. Partial weights stay in.
  • Noise: channels independent → var(pj) = Σc scj²·W2cj/Wcj², covariances for all lags d, with scj = mc(φj)/√(Bc·binDt) and each channel's own fitted level mc.
  • Output toa.nChanUsed. Single-channel folds give bit-identical results to before.
Limits of equal weights

Equal weights are not optimal when channels differ in noise (heavily blanked channels, carrier channels), and the exclusion rule can drop whole channels: 1-turn sub-ints with 100 µs blanks removed channels 110–115 everywhere, more data lost than blanked. Hence A2c.

6. Optimal weighting (A2c-1, 7 Oct) — the default in main.m

'Weighting','optimal' fits all channels at once:

profcj = ac + b·sc·T(φj − τ) + noise

a baseline ac per channel, one amplitude b times the known relative gain sc ('ChannelGain', default 1: observer knowledge of the pulsar spectrum × bandpass), and one τ.

Why one common amplitude, not one per channel

At −54 dB each channel's pulse has SNR ≪ 1 per sub-int; 128 free amplitudes would fit noise. One amplitude with a known spectral shape uses all channels' information for the one thing that matters, the shift.

  • Weights 1/variance per bin and channel (radiometer model with the current fit, or per-channel off-pulse residuals), iterated to convergence (|Δτ| < 10⁻¹², ≤ MaxIterations 10).
  • For fixed τ, ac and b by weighted least squares; τ maximizes N(τ)/√Dn(τ), the weighted matched filter: FFT correlations on the upsampled grid, a bounded search (fminbnd), then Newton on the analytic slope (a value-only search stops at ~10⁻¹⁰ turns).
  • Error bars: sandwich Cov = A⁻¹BA⁻¹, A = JᵀWJ, B = JᵀWΣWJ, with the full covariance Σ of every channel (all lags). The weights ignore neighbour covariances (correlation ~0.26, small loss); the error bars do not.
  • Empty bins weigh nothing, so there is no exclusion rule and no dips; nChanUsed = channels with data; new output chanBaseline. amp = b·Σsc (the summed pulse), baseline = Σac.
Why the sandwich form

The weights are an approximation of the inverse covariance (they ignore neighbour correlations). The sandwich estimator is honest even when the fit's weights are not exactly the inverse covariance; the plain A⁻¹ would only be right if they were.

A side benefit seen in B4: weighting by 1/level² is a built-in notch for narrowband RFI. A carrier that cut the full-band SNR to 74 leaves the channel path at 92.

7. The template

main.m uses gaussianTemplate(nBin, ephem.profileFWHM): a periodic Gaussian, peak 1 at bin 1 (images at −2…+2 turns summed). estimateTOA accepts any [NBin × 1] profile with phase 0 at bin 1, so real pulsars need only a different template source (a multi-component model or a high-SNR observed profile); its phase 0 then defines the TOA.

Bins must be fine compared with the template (warning since 9 Oct)

A profile bin is the pulse averaged over a time bin (binDt·f₀ turns) and spread over ~1 phase bin; the template is the unsmoothed pulse at the bin centres. estimateTOA warns (estimateTOA:resolution) when r = max(binDt·f₀, 1/NBin) is more than 1/5 of the template's narrowest width at half maximum w, and returns both in info.binResolution / info.templateWidth. Measured at −5 dB (rms error ÷ error bar, 1.04 with fine bins): time bins of w/2.5 → 2.04, w/5 → 1.08; phase bins alone of w/1.6 → 1.16, w/2.4–6.4 → 1.05. Coarse time bins are the critical side. Main's settings: r = w/102.

9. Validation

  • Noise-free (1 s, 99 TOAs): median σ 0.466 µs vs 0.469 µs from a NumPy Monte Carlo; rms/pred 1.053; χ² 109.9/99.
  • −5 dB Monte Carlo (10 noise seeds, 90 TOAs): rms/pred 0.950 ± 0.075, χ²red 0.91, 72 % within 1σ; σ only 0.5 % above the exact optimum.
  • SNR sweep −25…+20 dB: error bars honest for SNR per sub-int ≳ 5 (good TOAs); outliers below that, removed by detection.
  • Tests tests/testChannelTOA.m (A2a: bit-identical full band, error bars = explicit full-covariance formula to 4·10⁻¹⁶, channel vs summed fold) and tests/testOptimalTOA.m (A2c-1: equals FFTFIT for one channel to 1.7·10⁻¹⁶ turns; explicit sandwich; Monte Carlo with exact covariance: unbiased, pulls std 1.006–1.037, scatter 0.955–0.963 of equal weighting).
