Bugs and lessons

Bugs found and fixed so far, and what each one taught. Many conventions on Conventions and why exist because of one of these.

Findings that changed the design

Not bugs, but results that changed a plan:

  • Narrow-channel noise (6 Oct). The radiometer model assumes independent time bins; in 3.125 MHz channels bins are correlated. → exact V, X(L) through the fold (powerCovariance, A1a).
  • No simple variance rule after blanking (experiment 3a). Errors up to ±45 % for W² and W models. → exact per-bin weights (blankingWeights).
  • W = 0 bins still had power (A3a). Filter-tail leftovers biased nearly empty phase bins by up to +285 %. → the fold drops their power.
  • White-input assumption for blanking (A3a). Channel samples are not white; ~1 % error in W for nearly empty bins. → the mean uses the true channel spectrum.
  • Exclusion rule lost data (A3a). Whole channels dropped from sub-ints with any empty phase bin. → optimal weighting (A2c).
  • Gamma threshold tail too thin (B2). 1.1× the intended false flags at 10⁻⁶. → exact phase-type thresholds.
  • Long detection windows blanked the bright pulse (B2). 14 % of on-pulse data at −5 dB with 256-sample windows. → windows ≤ 16 samples.
  • Radar sidelobes survive per-sample excision (B5b). Locked radar → 150 µs bias at −54 dB. → frequency guard ±7.
  • Rotating-radar sidelobe pulses are missed one by one (B5c). → periodic mask (B6, in progress).

Statistical lessons

  • Shared realizations make "independent" checks correlated. The phase D ratios (1.03–1.06) and the phase E T0 std (1.10) looked like a 5–10 % hole in the noise model; they came from the same 10 noise realizations. A long independent H0 run settled it (T0 std 1.008).
  • One seed can mislead. The +3.7 µs centroid offset was a 1.8σ fluctuation of seed 43, repeated by every run that used the same noise.
  • Quote the uncertainty of a check. With 8 TOAs a ratio of 0.84 is consistent with 1 (±25 %); with 90 TOAs ±0.075.
