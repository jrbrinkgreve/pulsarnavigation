Stages 5b–6b · Channelized front end

The default processing path. It splits the band into 128 channels of 3.125 MHz, dedisperses each channel coherently to one common reference, and detects each channel with an exact model of its noise.

Selected with frontEnd = 'channels' · RFI excision (excision = true, default) sits between channelizeIQ and dedisperseChannels; see RFI excision · block A, the default

Why a channelized front end

The full-band path worked and was validated first. Then a channelized path was put in front of everything else, for four reasons:

1 · RFI excision needs it

Real data contains RFI. At −54 dB one radar pulse outweighs about 80,000 pulsar pulses. So it must be blanked on the voltages, before dedispersion spreads it out. In a 3.125 MHz channel, a 2 µs radar pulse is about 8 samples in about 2 channels: easy to find, and cheap to remove. In the full band there is no place where it is that compact and that separate from good data.

2 · Memory at high DM

A full-band dedispersion filter grows with the sweep: it needs about 15 GB at DM 100. A channel's filter spans the sweep only at the channel's 4.17 MHz rate: about 10⁵ samples instead of 10⁸. And the channels are done one after another.

3 · Sub-band TOAs later

Arrival times per group of channels give a check of the DM from the data itself (planned; roadmap, longer term).

4 · Nothing is lost

Each channel is still dedispersed coherently, on its voltage, so there is no smear inside a channel (the full-band page shows what shifting channels would leave). The full-band path stays as the validated reference: with all new options off, every changed function reproduces its old output bit for bit.

5a · channelizeIQ validated

info_chan = channelizeIQ(inFile, outBase, fs, fLO, fLow, fHigh, 'ChanWidth', 3.125e6, 'T0', info_IQ.t0)

Full interface and help text of channelizeIQ →

In short

It splits the 800 MHz IQ stream into 128 channels that tile 1.2–1.6 GHz exactly. Each channel is a complex voltage stream at 4.17 MHz, written to its own file.

What a channel is

Channel j is exactly what a separate receiver would give. Mix down by the channel centre fc,j = fLow + (j − ½)·ChanWidth (LO phase 0 at input sample 0), low-pass with zero phase, and keep every D-th sample:

\[ y_j(m) = \sum_n h(mD - n)\; x(n)\; e^{-i 2\pi (f_{c,j} - f_\mathrm{LO})\, n / f_s} \]
\(y_j(m)\)
complex sample \(m\) of channel \(j\) [V]
\(x(n)\)
complex IQ input sample \(n\) [V], at rate \(f_s\)
\(j\)
channel number, 1 … 128
\(f_{c,j}\)
centre RF frequency of channel \(j\): \(f_\mathrm{Low} + (j - \tfrac12)\cdot\)ChanWidth [Hz]
\(f_\mathrm{LO}\)
LO frequency of the IQ input [Hz] (fLO = 1.3 GHz)
\(f_s\)
IQ sample rate [Hz] (fs = 800 MHz)
\(h\)
the prototype low-pass filter (zero phase, unit DC gain)
\(D\)
decimation factor (192)
  • Sample m is at t0 + mD/fs: the filter delay is removed, so there is no TOA offset.
  • RF = fc,j + fbb, with no inversion. So each channel file is an ordinary IQ file, with fLO = fc,j and rate fs/D.
  • Unit DC gain: tone amplitudes and the passband power density are kept, and the channels' useful bands add up to the IQ band power.

How it works: a polyphase filterbank

Doing 128 separate mix–filter–decimate receivers would cost 128 times one receiver. The polyphase form gives exactly the same numbers far more cheaply. For each output time m:

  1. take a frame of L input samples and weight it by the prototype low-pass;
  2. fold the frame into K = 256 bins (add every 256th sample together);
  3. do one 256-point inverse FFT: every channel at once;
  4. correct each channel's phase from the absolute sample index (in double), and keep the 128 slots inside the band.
The exact formula

With fc,j − fLO = (kj + β)·fs/K (β = ½ here: band edges on the K-grid) and the prototype h(r) centred at G = (M−1)/2, zero-padded to L = P·K:

\[ \begin{gathered} y_j(m) = e^{-i 2\pi (k_j + \beta)(mD + G)/K} \sum_{p=0}^{K-1} e^{+i 2\pi k_j p / K}\, u_m(p) \\[4pt] u_m(p) = \sum_{q=0}^{P-1} h_b(p + qK)\; x(mD + G - p - qK) \end{gathered} \]
\[ h_b(r) = h(r)\, e^{+i 2\pi \beta r / K} \]
\(K\)
FFT size = number of channel slots, \(f_s/\)ChanWidth = 256 (not the dispersion constant)
\(k_j\)
integer FFT slot of channel \(j\)
\(\beta\)
fractional slot offset, ½ here (the band edges lie on the \(K\)-grid)
\(h(r)\)
prototype filter, taps \(r = 0 \ldots L-1\); \(M\) = 3853 non-zero taps, zero-padded to \(L = PK\) = 4096
\(G\)
the centre of the prototype, \((M-1)/2\) [samples]; it removes the filter delay
\(P\)
taps per polyphase branch (16)
\(h_b(r)\)
the prototype shifted by \(\beta\) slots in frequency
\(u_m(p)\)
input frame for output \(m\), weighted by \(h_b\) and folded into \(K\) bins (sum over \(q\))
\(p, q\)
bin index within the frame, and which of the \(P\) blocks of \(K\) samples

Prototype: a Kaiser-windowed sinc (the same design as the IQ filter), cut-off \(f_s/(2D)\), 80 dB stopband: 3853 taps (16 per branch).

Oversampling by 4/3

At fs = 800 MHz there are K = fs/ChanWidth = 256 channel slots. The decimation is D = K·3/4 = 192, so the channel rate is 4.17 MHz rather than 3.125 MHz. The prototype is flat to ±1.5625 MHz (± half a channel) and reaches its stopband at fs/D − ChanWidth/2 = 2.604 MHz.

Design choices

Oversample by 4/3, not a critically sampled filterbank

With D = K (critical sampling), each channel's transition region would alias into its own useful band, and mix the neighbours' signals in. Oversampling by 4/3 costs 33 % more samples, but keeps every channel's useful band clean. So the channels can later be treated as independent.

Each channel is an ordinary IQ file

Same time grid, same frequency convention, filter delay removed. So the already validated stages downstream (dedispersion, detection) run on a channel unchanged, and one test with tones pins down frequency mapping, LO phase, timing and gain at once.

128 channels of 3.125 MHz

The channel width is a trade-off.

  • Narrower channels blur a short RFI pulse in time: a channel of width B cannot show anything shorter than about 1/B. They also leave fewer independent samples per detected bin (the correlated-noise problem below).
  • Wider channels make a carrier or a GNSS signal cost more of the band, once its channel is down-weighted. They also lengthen each channel's filter.

At 3.125 MHz, a 2 µs radar pulse is about 8 samples in about 2 channels, and a carrier costs 1/128 of the band. And 800 MHz / 3.125 MHz gives a whole number of FFT slots: 256.

Tests (tests/testChannelizeIQ.m)

  • Tones at, beside and far from channel centres. Every sample equals the exact prediction to ≤ 2.7·10⁻⁷, the single-precision limit. This one test pins down frequency mapping, LO phase, timing and gain at once. The passband is flat to |H| = 1 ± 1.2·10⁻⁴, and the stopband is at −80.2 dB.
  • White noise. The channel power divided by Σh² is 1.0007. The passband level is 1.0004 of the expected value, and flat within ±3 %.
  • Real data (seed 43, −5 dB). The channel band powers add up to the IQ band power, to 1.00007. So there are no gaps and no double counting (Parseval). 0.1 s of data becomes 128 × 416,667 samples in 4.1 s (427 MB).

5b · dedisperseChannels validated

info_dc = dedisperseChannels(info_chan, outBase, DM, 'RefFreq', refFreq)

Full interface and help text of dedisperseChannels →

In short

It dedisperses every channel coherently, and brings all channels to one common reference frequency (1.6 GHz, the top of the band), so that afterwards a pulse arrives at the same time in every channel.

How it works

Each channel file is an ordinary IQ file, so the validated applyInverseDispersion runs on it, channel by channel, with three settings:

  • band = channel centre ± ChanWidth/2. The chirp filter is zero outside, which also removes the channelizer's transition region, so the channels tile the band exactly.
  • RefFreq = 1.6 GHz for every channel, with AllowRefOutsideBand. Each channel's chirp then includes its delay to the reference, so all channels come out aligned.
  • taper (EdgeFrac 0.02 of the channel: 62.5 kHz) inside each channel. Neighbours do not overlap, so their noise is independent. ∫W² = 390.0 MHz in total, the same as the full-band path.

Memory per channel: the filter spans that channel's sweep to the reference, at 4.17 MHz. For the bottom channel at DM 100 that is about 5·10⁵ samples, or about 120 MB. At DM 5 the FFT sizes are 2¹⁴…2¹⁸, the largest leakage is 6·10⁻⁸, and all 128 channels take 1.7 s.

Design choices

Reuse applyInverseDispersion

It was already validated, including its leakage check and fully supported range. The only change needed was the AllowRefOutsideBand option, and with it off the full-band output is bit-identical. One validated kernel, two front ends.

Align the channels with the chirp itself, not a separate shift

Alternative: dedisperse each channel to its own centre, then shift it by its delay to 1.6 GHz (a whole number of samples plus a fractional delay: an extra FFT pass per channel).

Why not: the inverse chirp is exact for any reference: its phase is the dispersion term, a pure delay and a constant. With the common reference, the delay is part of the same filter. That costs nothing extra, and needs no interpolation.

A taper inside each channel

Alternative: overlapping, power-complementary tapers, so that the summed band stays flat at the channel boundaries.

Why not: overlapping neighbours would share noise, and every later step would have to carry that correlation. With the taper inside each channel, the channels are exactly independent. The price is a small notch at each of the 127 boundaries. In total these cost the same 2.5 % of band power as the full band's two edges.

The channelized front end and these three design choices (4/3 oversampling, alignment by the chirp, a taper inside each channel): 6 Oct 2026, block A.

Tests (tests/testDedisperseChannels.m)

  1. Regression: the full-band applyInverseDispersion with defaults is bit-identical to test_IQ_dedispersed.dat.
  2. Commutation, the precise test. It compares channelize(full-band dedispersed) with dedisperseChannels(channelize(IQ)). Both are linear filters, so the order must not matter. In channels 4–125 the correlation is ≥ 0.999993, the phase difference ≤ 1.2·10⁻⁵ rad, and the power ratio 1 ± 3·10⁻⁵. This proves that the per-channel chirps, the delays between channels and the phases are exact.
  3. End to end. The TOAs of the channel path and of the full-band path on the same data (seed 43, −5 dB) agree: over 8 TOAs the mean difference is +0.19 µs and the rms 0.51 µs (0.18σ). The two paths keep slightly different parts of the same noise (correlation 0.979), so their differences should scatter by σ·√(2(1−ρ)) = 0.205σ. χ² is 5.98 for 8 TOAs: consistent.
  4. Time-bin noise of the summed channel power. The variance is 0.884 of the radiometer value (predicted 0.888 ± 0.005), and the lag-1 correlation 0.054 (predicted 0.052 ± 0.004). This test revealed the narrow-channel effect below.

powerCovariance: exact noise of detected time bins validated

noise = powerCovariance(chanWidth, edgeWidth, fs, nPerBin, ...)

Full interface and help text of powerCovariance →

The problem it solves

The radiometer equation, var = m²/(B·Δt) with independent time bins, assumes B·Δt ≫ 1. In the full band B·Δt ≈ 400. But in a 3.125 MHz channel with 0.96 µs bins it is only about 3. The detected power stays correlated for about 1/Bch ≈ 0.3 µs, which is a good part of a bin.

Two things follow. Each bin has less variance than the formula says: 0.888 of it. And neighbouring bins are correlated: +0.046 at lag 1.

The exact formula

A bin is the mean of |y|² over n samples. For Gaussian y with normalized autocorrelation R (Isserlis, see physics), relative to the radiometer value:

\[ V = \frac{C(0)}{\mathrm{rad}}, \qquad X_L = \frac{C(L)}{\mathrm{rad}}, \qquad C(L) = \frac{1}{n^2} \sum_{a=0}^{n-1} \sum_{b=0}^{n-1} \left|R(a - b + Ln)\right|^2, \qquad \mathrm{rad} = \frac{1}{n}\sum_{l} \left|R(l)\right|^2 \]
\(V\)
variance of one detected time bin, relative to the radiometer value \(m^2/(B\,\Delta t)\)
\(X_L\)
covariance between a bin and the bin \(L\) further, on the same relative scale
\(L\)
lag in time bins, 1 … Lmax (not the frame length \(L\) above)
\(C(L)\)
the Isserlis sum for bins \(L\) apart (relative to \(m^2\))
\(\mathrm{rad}\)
the radiometer value \(1/(B\,\Delta t)\) written as a sum over \(R\)
\(n\)
channel samples per time bin (4 at 0.96 µs)
\(a, b\)
sample indices within a bin
\(R(l)\)
normalized autocorrelation of the channel voltage \(y\) at lag \(l\) samples, \(R(0) = 1\)
\(m\), \(B\), \(\Delta t\)
mean bin power; bandwidth \((\int S)^2/\int S^2\) of the channel spectrum \(S = W^2\); bin length
  • Summed over all lags, V + 2ΣXL = 1 exactly: the independent-bin model is right for long sums, wrong bin by bin.
  • The spectrum is W² of the per-channel taper; the chirp is all-pass and drops out.
  • Lmax = the smallest lag with V + 2Σ≤LX ≥ 1 − 0.002. The slow 1/L² tail comes from the sharp channel edges.

Why carry this exactly instead of ignoring it

Within one phase bin the two effects nearly cancel: the variance is 0.987 of the simple model. So the effect looks negligible. There are three reasons to carry it anyway:

  • error bars and false-alarm thresholds must be exact at weak signal;
  • phase bins can be shorter for other pulsars;
  • the same machinery is needed anyway for blanking, where the effect is large (±45 %).

So V and X(L) travel with the data through the fold (NoiseCoeffs).

6b · detectChannels validated

info_det = detectChannels(info_dc, outFile, f_out)

Full interface and help text of detectChannels →

In short

It runs the validated detectPower on every dedispersed channel and interleaves the results into one float32 file of [128 channels × time bins], the layout foldProfile reads. Temporary files are deleted.

  • Bin rate fs/round(fs/fout): a whole number of channel samples per bin, here 4 samples, 0.96 µs, 1.0417 MHz (one warning if this differs from the requested 1 MHz).
  • Info: detectPower's fields used by the fold (file, nChan, N, binTime0, binDt, fullySupportedBins, byteOrder, chanFreqs, …) plus chanWidth, chanMeanPower, BnoiseChan, BnoiseTotal and noise (the powerCovariance struct: the same for every channel and bin without blanking).
  • 0.5 s for 0.1 s of 128 channels.
A whole number of samples per bin

A bin boundary inside a sample would need interpolation and break the exact noise model. 4 samples at 4.17 MHz = 0.96 µs is close to the 1 µs of the full-band path.
