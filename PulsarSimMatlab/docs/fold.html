Stage 7 · Folding: foldProfile validated

Average all turns at the same rotational phase, so the pulse adds up and the noise averages down. The fold keeps not just the profile but everything needed to know its noise exactly: how much data went into every phase bin, and how strongly neighbouring bins share noise.

[info, fold] = foldProfile(info_det, outFile, f0, 'F1', F1, 'TRef', TRef, 'NBin', nBin, 'SubintPeriods', n, ...)

Full interface and help text of foldProfile →

Used by both front ends. Channel path adds 'NoiseCoeffs' (no excision) or 'DataWeights' (with excision).

Idea

Phase model from the ephemeris (observer knowledge only):

φ(t) = Φ0 + f0·(t − Tref) + ½·F1·(t − Tref)²

With Tref = first true pulse centre (T/2, from ephem.TRef) and Φ0 = 0, every true pulse peak is at an integer phase. Each detected time bin is assigned to phase bins by its phase; averaging over N turns improves the SNR by √N.

Algorithm

  1. Use only fullySupportedBins (data that saw the complete dedispersion sweep).
  2. Phase per time bin, in double.
  3. turn = round(φ), frac = φ − turn ∈ [−½, ½]: each turn runs from half a turn before its pulse to half a turn after, so cuts fall between pulses.
  4. NBin phase bins; bin j (1-based) is centred at phase (j−1)/NBin; negative phases wrap to the end. Position x = frac·NBin.
  5. Linear assignment (default): j0 = ⌊x⌋, a = x − j0; the time bin contributes with weight 1 − a to bin j0 and a to bin j0 + 1.
  6. Accumulate per (phase bin, sub-int, channel): sum Σw·P, weight Σw, weight2, weightX (below).
  7. Sub-integrations of SubintPeriods turns (or SubintTime); prof = sum/weight; profTotal = Σsum/Σweight over all sub-ints.
  8. Per sub-int: turnRef (the middle turn), tRef = the time where φ = turnRef (stable quadratic root), fRef = spin frequency at tRef, tMean, nTimeBins. These define the TOA later.
  9. Saved to a .mat file (fold + info). Vectorized accumarray, chunked reading.
Why linear assignment, not nearest bin

Linear assignment preserves each sample's mean position exactly. 'nearest' gave a 0.5 ns bias: the 1 µs time grid and the 9.765625 µs phase grid repeat identically every turn, so the rounding errors do not average out. The price is that neighbouring phase bins share data and their noise is correlated, which the fold tracks explicitly.

The weights: what each field is for

For phase bin j of one sub-int, sumj = Σk akj·Pk, with akj how much of time bin k went into phase bin j.

FieldFormulaPurpose
weightΣk akj (with data weights: Σ a·W)normalizer: how much data is in bin j; prof = sum/weight
weight2Σk akj² (× V, plus lag terms)var(profj) = σ²·weight2/weight² (variance of a weighted mean)
weightX(:,:,:,d)Σ akj·ak,j+d (× correlations)cov(profj, profj+d) = σ²·weightX/(weightj·weightj+d)

Example: a time bin 30 % of the way from bin j to j+1 gives 0.7 and 0.3, adds 0.49 and 0.09 to the two weight2 values and 0.21 to weightX. Over many turns the ratios settle at W : W2 : WX = 1 : 2/3 : 1/6, a neighbour correlation of 0.25, exactly the 0.2484 measured in the long noise-only run.

Why weightX matters (a real bug once)

With linear assignment a phase bin looks like it has variance σ²/14.7 per turn instead of σ²/9.77, because it shares data with its neighbours. Ignoring the positive covariance underestimates the variance of any sum over bins (a TOA, a matched filter) by ~1.5×. The fold check predicted a centroid scatter of 0.226 µs instead of the correct 0.277 µs until weightX was added (bugs and lessons #8).

σ² itself is not stored in the fold: the consumers (estimateTOA, detectPulsar) compute it from their noise model (radiometer equation with the fitted level, or off-pulse residuals). The fold only provides the geometry.

Correlated time bins: 'NoiseCoeffs' (A1a, 7 Oct)

In a narrow channel neighbouring detected time bins are correlated (variance V, covariance X(L) at L bins apart, relative to σ² = m²/(B·Δt); see powerCovariance). A phase-bin sum then has

cov(Sj, Sj+d) = σ²·ΣkΣk′ akj·ak′,j+d·c(k′ − k),   c(0) = V, c(±L) = X(L)
  • 'NoiseCoeffs' = [V X(1..Lmax)]; default 1 = independent bins (full band), bit-identical to before.
  • weight2 = var(Sj)/σ², weightX = cov(Sj, Sj+d)/σ² for phase lags d = 1..D, with D = ⌈Lmax·binDt·f·NBin⌉ + 1 (3 for the channel data at 10 ms / 2048 bins).
  • Every pair of time bins L apart in the same sub-int adds X(L)·a·a′ to its pair of phase bins; the last Lmax time bins of a chunk are kept for pairs with the next chunk (addLagPairs).
  • Effect for the channel data: phase-bin variance 0.987 of the old model, lag-1 correlation 0.258 instead of 0.250.

Tests (tests/testFoldWeights.m 1–3): the four pre-A1 reference folds reproduced bit for bit; weight2/weightX = Aᵀ·C·A built explicitly to 6·10⁻¹⁶; measured fold noise on 128-channel data vs new / old model: variance −1.4σ / −13.1σ, lag 1 +0.6σ / +5.9σ. The old model is clearly rejected, the new one fits.

Data weights per channel: 'DataWeights' (A1b, 7 Oct)

With excision, detected bin k of channel c has mean Wkc·mc (valid fraction W), variance Vkc·σc² and covariance Xkc(L)·σc² with bin k+L, all exact from blankingWeights. The fold uses them:

  • weight = Σ a·W, so prof = Σa·P / Σa·W is unbiased even when blanking depends on pulse phase;
  • weight2 / weightX as in A1a, with the per-bin Vk and Xk(L);
  • a time bin with W = 0 adds no power to the sum either (found in A3a: filter-tail leftovers biased nearly empty bins);
  • output arrays get a channel dimension: weight, weight2 [NBin × nSub × nChan], weightX [NBin × nSub × nChan × D]; prof, profTotal per channel with its own weights;
  • option value: an info struct with file, nChan, N, Lmax, byteOrder; replaces NoiseCoeffs (error if both).
Why divide by Σa·W instead of Σa

A bin with W = 0.5 contributes half the power to the numerator and 0.5 to the denominator: it counts as half a sample with the right mean. A fully blanked bin contributes nothing. The test with fake blanking at phase 0.30–0.36 shows the difference: the weighted fold is unbiased (−0.0019 ± 0.0009), a naive fold is off by −0.574, exactly the predicted 1 − 0.425.

Tests (tests/testFoldWeights.m 4–6): constant weight file = NoiseCoeffs fold bit for bit; random weight streams = AᵀW and AᵀCA to 7·10⁻¹⁶; fake blanking unbiased and noise as modelled. Cost: 1.8 s for 0.1 s of 128 channels with weights (0.25 s without).

Choosing NBin and the sub-int length

NBin = 2048 is more than enough

Binning only costs information if bins are coarse compared with the pulse: σeff² ≈ σt² + Δ²/12. For the simulated pulsar Δ²/12 ÷ σt² = 4·10⁻⁵, for J0437 2·10⁻⁴: negligible. Rule of thumb NBin ≳ 10·P/W50 (~400 for J0437). Detection and matched-filter SNR do not depend on NBin once bins are fine. What NBin does change is cost: weights scale as NBin × sub-ints × channels × lags, so long observations will likely use fewer bins or sub-bands.

NBin and f_out together: every phase bin needs data (warning since 9 Oct)

Consecutive time bins are f·binDt·NBin phase bins apart. Above 1, a sub-int can leave phase bins empty, and estimateTOA / detectPulsar (MinCoverage 1) then reject every sub-int. Example from the f_out sweep: f_out = 100 kHz (10.08 µs bins) with NBin 2048 and 1 turn per sub-int fills 1984 of 2048 bins, so the run gives no TOAs at all. foldProfile now checks the time grid of the first complete sub-int before folding and issues foldProfile:coverage with the limits: NBin ≤ time bins per turn, binDt ≤ 1/(f·NBin), or more turns per sub-int. Main's settings (0.96 µs bins, 4.9 µs phase bins) are far inside the limit.

Sub-int length: SNR ≥ 6–7

One profile of all turns gives the same precision as the weighted mean of per-sub-int TOAs (constant profile, exact phase model). Sub-ints exist to validate error bars, see drift (phase-model errors, motion, clock, position error) and catch bad data. Below SNR ≈ 6 per sub-int TOAs start to lock onto noise peaks, so the number of turns per sub-int is N = (SNRtarget/SNRturn)², with SNRturn ≈ 373·ρ here. See threshold sweep. An adaptive choice from the data is on the roadmap.

Limits

Not stored: covariance between consecutive sub-ints

With correlated time bins, the last bins of one sub-int correlate with the first of the next. Only the 2–3 phase bins at the boundary (phase 0.5, off-pulse) are affected, by ~1–4 % of their variance. Negligible for TOAs (template slope ≈ 0 there) and detection (~10⁻⁵).
