References

Every source these pages cite, with how far each one was checked.

A number in square brackets on any page, such as [7], points to an entry on this page. The entries are numbered in the order in which the pages first cite them, following the sidebar. A number never changes once it is given, and a new reference gets the next free number. The links on this page lead to the internet; every other page still works without it.

1 · How far each source was checked

A citation is only worth something if the source says what the page claims. Each entry therefore states what was confirmed, in one of three grades:

GradeWhat it meansEntries
Source readThe text was opened, and the statement that the pages rely on was found in it. The entry names the equation, table or section.17
Through a second sourceThe bibliographic record is confirmed. The content is confirmed in another source that quotes it, which the entry names.11
Record onlyThe bibliographic record is confirmed. The pages cite the work only as the origin of a named method or data set, and its text was not opened.31

Where a source and a page disagree, the page is not changed silently: the difference is recorded in the session log logs/2026-11-24_docs-references.md. The register behind this page, with every check in full, is logs/references.md.
